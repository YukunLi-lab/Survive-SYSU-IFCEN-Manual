# 毕业去向数据与口径

本目录对应“欢迎来到中法核”的数据图。所有人数来自编写者提供的2016—2021届硕士去向长图和2021—2025届就业数据PDF。没有用网页宣传数字替换附件数据，也没有推测未披露的本科总人数。

## 文件

- [masters.csv](masters.csv)：2016—2025届硕士主图，逐行含来源、页码与待定说明。
- [undergraduates.csv](undergraduates.csv)：2021—2025届本科已披露升学与就业人数；空字段表示未披露，不是零。
- [source-records.json](source-records.json)：保留不同版本、院校逐项和原行业表，不把互相矛盾的类别静默改写。
- [sources.json](sources.json)：六份附件的原文件名、页数或尺寸和SHA-256。原始文件保持不变，未随仓库公开上传；无已核定的原始发布网址时不杜撰链接。
- [绘图脚本](../../scripts/plot_graduate_outcomes.py)：从两个CSV作图；需Matplotlib，图像存入 `assets/figures/`。

## 主图来源选择

硕士2016—2021届统一采用《中法核2022就业数据.pdf》第4—6页的回溯附图；2022—2025届采用各届PDF第1页正文。这个选择用于使2016—2021的回溯部分保持同一版资料，不代表它与早期长图是一致的数据，也不证明每届统计对象和时间完全相同。

硕士主图严格沿用“工作栏”和“深造/读博栏”的原标签。2022附图的2018深造15人含待定1人，2021工作51人含待定1人，斜线标示相应人数；2016深造12人含读硕1人，2017深造16人含读硕3人，故不能统一称为读博率。未见待定标签不等于对所有去向落实状态重新核实过。

2021当年PDF第1页另记70人=就业46+读博22+待定2；同PDF第6页及原长图则为70=工作45+深造25，深造25含待定3。主图用2022附图73=工作51+深造22，三种快照不相互拼接。2024第4页23=18名硕士+5名博士，主图只用正文18名硕士。2025硕士总览截至2026年2月，读博子段截至2026年1月，本科落实率截至2025年底。

## 本科处理

2021—2023升学49、59、40人是逐条加总原院校列表得到；原文另给79.03%、74.68%、69.0%的升学率。2024、2025正文分别直接给52、69人，并与列表相符。2024就业9人来自正文；2025就业29人来自17根整数柱的逐项加总。其余年份就业人数空缺。

五份资料均没有直接列出本科毕业总人数，因此不从四舍五入的升学率或“超过90%/86%”反推分母，不将“未升学”改称就业，不将52+9或69+29称为毕业总人数。升学率和去向落实率不是同一指标。

本科升学的内地/内地以外按原列机构办学地点归类，香港计入内地以外；香港城市大学（东莞）计入内地。2025升学名单包含东京太阳树语言学校1人，保留在原“升学”标签下，不能把69人全称为研究生录取。2022名单“圣埃蒂安”和“圣太田”两个相近校名各列1人，均照录原条目，不假设为同一人而删除。

## 行业与机构限制

2021—2023有原行业表，2024、2025也有单位或行业图。2025行业粗表给高科技/IT46、核能/能源10、科研/事业3、公务员/编制3，但同报告中国广核集团一项已列11人。未公开的单位—行业映射不能由本章擅自补齐，因此不据此绘制统一跨年的行业趋势；原表保存在JSON中。模糊单位名称保留待核标签，人数清晰也不擅自认定名称。

科研助理等待博士指标已在各报告工作范围内（2021为3、2022为2、2023为4），不能再叠加为另一批已获博士录取者。

## 图表方法与工具参考

绘图采用从零起点的计数条形图，直接标人数；不做平滑、不画推测值、不加统计误差条；缺失与零分开表示。图旁附表提供文字替代。颜色之外使用直接数字和待定斜线表达类别。图表规范参考：Timothy Kassis, Vinayak Agarwal, Yuhuan He, Darshil Patel, Aubrey M. Brueckner (2026), [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://arxiv.org/abs/2609.00065)（已核对当前arXiv条目，引用不固定版本后缀）。数据来源仍仅为上述六份用户附件。
