# 毕业去向数据与口径

本目录对应“欢迎来到中法核”的毕业去向总览与细分图。人数仅取自编写者提供的2016—2021届硕士去向长图和2021—2025届就业数据PDF，不用外部网页的宣传数字替代附件，也不推测未披露的本科毕业总人数。集团官方网页和QS官网只用于核实机构身份、集团关系与学校排名分组，不提供新的毕业人数。

## 阅读入口与文件

- [完整机构清单](detailed-destinations.md)：按届列出深造学校／机构、目标学位与就业单位，表内不设置来源项。
- [masters.csv](masters.csv)、[undergraduates.csv](undergraduates.csv)：原总体去向图的数据，保留各自统计口径；本科空字段表示未披露，不是零。
- [employment-groups.csv](employment-groups.csv)：硕士2016—2025届与本科2021—2025届的就业集团人数；未披露字段留空。
- [employment-records.csv](employment-records.csv)：已列就业单位、人数及集团类别。单位未明的差额与具体单位分开。
- [degree-types.csv](degree-types.csv)：目标学位分类，区分博士、硕士、学位未注明、非学位学习与待定。
- [study-groups.csv](study-groups.csv)：逐年学校分组，内地类别与QS 2025档位互斥。
- [study-records.csv](study-records.csv)：逐条深造机构、人数、目标学位和学校类别。
- [source-records.json](source-records.json)：原总览的不同版本、院校条目与原行业表。
- [classification-audit.json](classification-audit.json)：本次逐单位、逐学校转录、集团归属、QS 2025核验、选用快照与未采用的矛盾记录；核验链接不放入图表和统计表。
- [sources.json](sources.json)：六份附件的文件名、页数或尺寸、SHA-256。原始附件未修改，也未随仓库公开上传；没有已核定的原始发布网址时不杜撰链接。
- [总览绘图脚本](../../scripts/plot_graduate_outcomes.py)：由总览CSV生成原两张去向图。
- [细分绘图脚本](../../scripts/plot_destination_details.py)：从细分CSV生成集团、学校与学位图；需Matplotlib和NumPy，并安装中文字体。

## 总体去向采用什么口径？

硕士2016—2021届总览统一采用《中法核2022就业数据.pdf》第4—6页的回溯图；2022—2025届采用各届PDF第1页正文。2016—2021届按“总数／工作栏／深造栏”依次为79／67／12、70／54／16、68／53／15、70／53／17、52／42／10、73／51／22。早期长图的另一组数字依次是79／65／14、69／53／16、62／46／16、64／49／15、46／37／9、70／45／25，两版均保留在JSON，不混合补齐。

回溯图的2018届深造15人含待定1人，2021届工作51人含待定1人，图中斜线已经包含在对应栏内。2016届深造12人含再次读硕1人，2017届深造16人含再次读硕3人，故整列不能统一称为读博人数。早期长图另有2018深造16人含待定1人、2019工作49人含待定2人、2021深造25人含待定3人的情况。长图右边缘被截断而不能读取的人数保留为null，不由总数差额补齐。

2021当年PDF第1页另记70人＝就业46人＋读博22人＋待定2人；该PDF旧地图为70人＝工作45人＋深造25人。2024第4页23人为18名硕士与5名博士合计，总览只采用正文18名硕士。2025硕士总览截至2026年2月，读博子段截至2026年1月；本科去向落实率截至2025年底。

## 就业集团归并

按实际用人单位的集团归属归并中广核、中核、国家电投、华能；研究院、核电站、工程公司和子公司纳入同一集团。同一用人单位不因多个股东重复计算。已知不属于四集团的单位列“其他单位”；单位未披露或名单无法对应的差额列“单位未明”，不默认为其他单位。

2016—2020届硕士采用2022年回溯单位地图，2021届改用当年正文完整单位名单46人，2022—2025届采用当届正文与单位图。各届细分总数分别为67、54、53、53、42、46、53、38、14、62，合计482人；其中中广核260人、中核14人、国家电投15人、华能0人、其他已知单位190人、单位未明3人。479人可按已列单位或去向类别归组，另有1条单位名称字迹不清、2人属于栏目与单位清单的差额。

2019年名单合计52人、工作栏53人；2020年名单合计41人、工作栏42人，分别差1人，均单列单位未明。2025年另有上海一家科技公司1人的名称字迹不清，不能确认集团，列单位未明。2021回溯图有单位重名条目、分栏人数及工作栏51人之间的不一致，所以不把它硬拆为单位；原始转录与矛盾保留在审计JSON，细分采用当年正文46人。总览工作栏十届累计487人，细分累计482人，相差5人来自2021快照选择，不能把相差人数另建一个单位类别，也不能将两套人数相除算就业率。

2017、2018年英文“China Nuclear Power Engineering Co., Ltd.”容易混淆；原图中文明确为中广核工程，按中文身份和官方集团关系归中广核。上海核工程研究设计院归国家电投；江西天红归国家电投；中国聚变能源归中核；聚变新能（安徽）列其他单位。中国工程物理研究院、科学院研究所不按名称中的“核”字归中核。

2025本科就业图17个单位条目合计29人，分组为中广核2人、中核2人、国家电投5人、华能1人、其他单位19人。2024本科仅披露就业9人，没有单位清单，故9人列单位未明，四集团及其他单位均显示未知或未披露；2021—2023本科就业总数与单位未披露，不填零。

科研助理等待博士指标仍属于原工作范围（2021为3人、2022为2人、2023为4人），不能再次叠加为已读博人数。学校和科研机构出现在就业名单时仍按就业记录，不能转入深造名单。

## 目标学位与学校分组

“硕士／博士”指接下来攻读的学位，与毕业前的学生层次分开。2016—2025届硕士深造栏合计148人，明确博士143人、再次读硕4人、待定1人。2021—2025届本科升学名单合计269人，其中268人没有在附件中明确目标学位，1人为语言学校。不能把本科的268人全推定为读硕，也不能把“附件中没有明确标注博士”理解为实际无人读博。

内地机构按办学地点和身份依次分为互斥六类：清北复交（清华、北大、复旦、上海交大）、西交（西安交大）、中大本校、其他211、其他内地高校、科研院所。“其他211”不再包含前三组，但包含其余985高校。香港列内地以外；香港城市大学（东莞）列其他内地高校。

内地以外学校统一核对[QS 2025世界大学综合排名](https://www.topuniversities.com/world-university-rankings/2025)，以官方院校页面的2025历史排名为准，前200包含第200名，201—500包含第500名，500名以后独立一组；不混用学科排名、其他机构排名或官网当前年份顶部排名。

未列综合榜的专门学校、研究中心、企业和语言学校，以及附件名称不能唯一匹配排名主体的条目，均单列“境外未列综合排名／归属未明”，不当作QS500+。附属学院与旧校名仅在关系明确时映射：例如巴黎高等化学学院使用已核明的PSL成员关系，巴黎十一大使用已核明的巴黎萨克雷继承关系；CEA、EDF等只有实验室或企业名称时，不猜测学位授予大学。Rutgers仅写商学院、无法唯一核定校区的条目，也保留在未明组。对应关系和官方链接逐条记录在审计JSON的`rank_reference`中。

学校分组累计：硕士清北复交7、西交2、中大48、其他211为5、其他内地高校1、科研院所3、QS前200为36、201—500为6、500名以后3、境外未列综合排名／归属未明36、待定1，合计148。对应本科分别为16、4、217、3、3、6、14、1、0、5、0，合计269；本科未列综合排名组含语言学校1人。

2021—2023本科升学49、59、40人由院校名单加总，正文另给升学率79.03%、74.68%、69.0%；2024、2025升学52、69人与名单一致。所有本科PDF都未直接给毕业总人数，不由四舍五入的升学率或“超过90%／86%”反推分母，不把未升学人数视作就业，不把52＋9或69＋29当作毕业总人数。2022本科“圣埃蒂安”和“圣太田”各列1人，两条均保留，不能凭相近译名删除其中一人。

## 图表方法与工具参考

图表和统计表不设置来源栏或来源脚注，出处、原页码、单位归属和排名链接集中在本文与JSON。计数条形图从零起点，直接标人数；不平滑、不填推测值、不添加没有依据的误差条。缺失与零分开表示，2024本科未知的集团分布不显示成0。学校分组和目标学位是两种独立维度，同一人各在对应维度出现一次，不将两张图的人数相加。

学校分组图按统一QS 2025口径作分类，并非各届毕业当时的学校排名变动图。所有累计人数均为材料中不同届别、不同统计时点的相加，不能据此估计新生将来的录取或就业概率。

原行业粗表仍保留在JSON，但不用于跨年集团归并。2025硕士原行业表“核能／能源”为10人，同报告中广核集团已列11人，两者显然不是可直接互换的分类，不能强行建立单位—行业映射。

图表规范参考：Timothy Kassis, Vinayak Agarwal, Yuhuan He, Darshil Patel, Aubrey M. Brueckner (2026), [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://arxiv.org/abs/2609.00065)。该条目用于方法参考；毕业人数仍仅来自本节列明的六份附件。
